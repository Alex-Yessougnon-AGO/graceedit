# 04 — Information Architecture

## Primary mobile structure
1. Home
2. Projects
3. Create
4. Templates
5. Profile/Settings

Create may be visually emphasized as the main action.

## Home
- Greeting
- Quick actions
- Continue editing
- Recent projects
- Templates
- Improve a video
- Help

## Projects
- Recent
- Favorites
- Archived
- Search
- Project cards with thumbnails

## Create
- New project
- Camera
- Gallery
- Template
- Quick creation
- Future project import

## Editor
### Beginner
Preview → contextual actions → timeline → undo/redo → save/share.

### Studio
Preview → timeline → track controls → inspector → effects/audio/text/captions → export.

## Templates
Sermon, Testimony, Worship, Announcement, Bible Verse, Quote, Social, Personal, future Business.

## Settings
Account, Appearance, Language, Accessibility, Storage, Export defaults, AI/privacy, Downloads, Notifications, Help, About, Licenses, Privacy, Terms.

## Future desktop/web
Same information architecture with persistent navigation, media bin, large preview, timeline, inspector and export queue.

## Future Creative Studio
The primary navigation may evolve to:
1. Home
2. Projects
3. Create
4. Templates
5. Assets
6. Brand
7. Profile/Settings

Create becomes a unified intent entry point:
- Video
- Poster / flyer
- Social post
- Thumbnail
- Image
- Audio
- Story / scenario
- Campaign
- Presentation / UI concept (future)

## Creative workspace
A future project can open in one of several focused editors while sharing the same underlying project:
- Video Studio
- Graphic Studio
- Audio Studio
- Story/Script Studio
- Campaign Studio
- UX/UI Studio

A campaign can contain multiple outputs generated from one source brief.
