# 11 — Product Roadmap

## Phase 0 — Foundation
Product research, PRD, UX, design system, project schema, commands, platform interfaces, license inventory and technical spikes.

## Phase 1 — Android MVP
Import, camera, preview, thumbnails, trim, split, delete, reorder, text, basic subtitles, audio, brightness, contrast, saturation, crop, rotate, undo/redo, autosave, 720p/1080p export and sharing.

## Phase 2 — First public release
Templates, recipes, automatic captions, better audio, better filters, project management, performance and sharing improvements.

## Phase 3 — Grace Intelligence
Jev format recommendations, template matching, edit recommendations, enhancement recommendations and export recommendations.

## Phase 4 — Smart editing
Silence detection, auto cuts, auto reframe, highlight detection, automatic shorts, caption cleanup and speech enhancement.

## Phase 5 — Studio
Multi-track, overlays, transitions, keyframes, masks, advanced color, advanced audio and speed curves.

## Phase 6 — Pro
Brand kits, custom fonts, presets, premium templates, batch export, 1440p, 4K30, 4K60 where supported, HEVC and HDR where supported.

## Phase 7 — iOS
Native Swift/AVFoundation media engine, iOS camera and shared project schema.

## Phase 8 — Desktop
Large-screen UX, keyboard workflows, proxy media, multi-panel Studio and batch export.

## Phase 9 — Web
WebCodecs/WASM experiments, local processing and optional cloud render fallback.

## Phase 10 — Cloud ecosystem
Only if justified: cloud projects, sync, collaboration, teams and marketplace.

## 4K strategy
Design the project model and export profile system for 4K now. Do not overwhelm MVP users with it. Show it only when source, device encoder, storage and product policy support it.

## AI strategy
Jev remains the decision layer. Other components may provide transcription, vision and audio processing. GraceEdit Core remains deterministic.

## Phase 11 — Creative Studio foundation
- Unified creative brief model.
- Asset registry and provenance.
- Brand Kit.
- Structured template system.
- Graphic scene graph.
- AI role registry.
- Provider abstraction.

## Phase 12 — AI Graphic Designer
- Posters/flyers.
- Social graphics.
- Thumbnails.
- Template recommendation by domain/audience.
- AI art direction.
- Editable typography/layout.
- Brand consistency checks.

## Phase 13 — Generative Media
- Image generation/editing.
- Voice/audio generation.
- Sound effects/music where providers and licensing permit.
- Video/clip generation where providers and device/cloud capabilities permit.
- Generation queue and asset management.

## Phase 14 — Story-to-Media
- Scenario/script.
- Storyboard.
- Shot list.
- Asset generation.
- Automatic assembly into video.
- Captions, thumbnail, poster and social variants from one project.

## Phase 15 — AI Creative Team
Specialized roles collaborate through structured artifacts rather than uncontrolled agent-to-agent conversation:
Creative Director → Designer/Video Editor/Copywriter/Audio Designer → Quality Reviewer → Export/Adaptation.

## Phase 16 — UX/UI Studio
- Wireframes.
- UI screens.
- Component suggestions.
- Design tokens.
- Responsive variants.
- Prototype flows.
- Developer handoff.

These phases remain optional and should be introduced only after the core editor and project model are stable.
