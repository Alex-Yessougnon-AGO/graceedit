# 21 — Brand Kit and Asset Library

## Brand Kit
A Brand Kit stores persistent creative context:
- logos and logo variants;
- primary/secondary colors;
- fonts;
- typography hierarchy;
- image style;
- icon style;
- preferred layouts;
- tone of voice;
- recurring slogans/phrases;
- prohibited colors/elements;
- spacing conventions;
- social format preferences.

## Asset Library
Assets include:
- user media;
- generated images;
- generated clips;
- audio;
- logos;
- fonts;
- templates;
- stickers/icons;
- thumbnails;
- exported variants.

## Collections
Users can organize assets into project, campaign, brand, event and personal collections.

## Search
Future semantic search can find assets by meaning, visual similarity, tags, colors, people/objects where privacy and local processing permit, and project context.

## Provenance and licensing
Each asset should expose source type and available licensing/provenance metadata. Assets with unclear commercial rights must be clearly identified before commercial publishing workflows.

## Reuse
A campaign can reuse the same logo, colors, typography, images and copy conventions across poster, video, thumbnail and social variants.
