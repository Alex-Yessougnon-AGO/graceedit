## Choix techniques à consigner obligatoirement
- **Base de données locale** : aucun moteur relationnel. Fichier JSON `state.json` dans `getApplicationSupportDirectory()/graceedit`, écrit par fichier temporaire puis `rename` (écriture atomique). Bibliothèques : `dart:convert`, `path_provider` 2.1.5 (licence MIT). Pas de `sqflite`, `hive`, `isar` ni `shared_preferences` utilisé dans `lib/`.
- **Bibliothèque de lecture vidéo** : `video_player` 2.9.5 (Apache-2.0), derrière les services existants. Le choix d'une lecture 100 % native (Media3 ExoPlayer côté Kotlin) reste ouvert : voir QUESTIONS.md.
- **Bibliothèque de rendu / export** : `androidx.media3` 1.9.2 — `media3-transformer`, `media3-effect`, `media3-common`, `media3-exoplayer`, toutes sous licence Apache-2.0. FFmpeg est explicitement écarté (licence GPL, AGENTS.md §3.10).
- **Version minimale d'Android** : `minSdk = flutter.minSdkVersion` (SDK Flutter 3.47.7, donc API 21). Conséquence pour IMP-03 : le sélecteur de fichiers du système (`ActivityResultContracts.GetContent`/`OpenDocument`) est utilisable dès API 21 ; `MediaPickerPlugin` s'appuie sur cet intent, donc `PermissionScreen` n'est affiché que si cet intent échoue. À confirmer sur un appareil API 21 réel.
- **Jeu d'icônes** : les 42 SVG fournis dans `design/icones/` (grille 24 dp, trait 2 dp, `currentColor`) sont copiés dans `assets/icons/` et rendus par `flutter_svg` 2.3.0 (**MIT**) derrière `GraceIcons` / `GraceIcon`. Les icônes Material ne servent plus qu'aux cas non couverts par le jeu fourni (aucune icône tierce supplémentaire, donc aucune licence supplémentaire).
- **Police Inter** : fichiers `Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf` dans `assets/fonts/`, déclarés dans `pubspec.yaml`. Licence OFL incluse : `assets/fonts/Inter-LICENSE.txt`.
- **Autres dépendances** (toutes sous licence permissive) : `flutter_riverpod` 2.6.1 (MIT), `go_router` 14.8.1 (BSD-3-Clause), `uuid` 4.5.1 (MIT), `intl` 0.20.2 (BSD-3-Clause), `path` 1.9.1 (BSD-3-Clause), `share_plus` 13.3.1 (BSD-3-Clause), `image_picker` 1.1.2 (MIT).
